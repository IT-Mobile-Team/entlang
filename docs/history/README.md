# History

One file per Linear ticket: `ENT-<nr>.md`, written by `/ent-finish` (or by hand from `_template.md`).

It records **why** things were done: decisions, rejected alternatives, verification and open points.
For how the system works today, see the dev docs. History files are a snapshot: don't edit them after
merge. If a later ticket changes a decision, its own history file says so and references the old one.
